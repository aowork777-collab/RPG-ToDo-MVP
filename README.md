# RPG ToDo App — ローカル確認版 2026.09.14

## 起動
Node.js 18以上が必要です。依存パッケージのインストールは不要です。
ZIPを展開し、package.jsonとserver.jsがあるフォルダで実行します。

```bash
cd ~/work/RPG-ToDo-App-Local-20260914
npm start
```

ブラウザで http://localhost:8080/ を開きます。
npmを使わず `node server.js` でも起動できます。
起動したターミナルは開いたままにしてください。終了はCtrl+Cです。

8080が使用中なら、以前のサーバーをCtrl+Cで終了するか、別のポートで起動できます。

```bash
PORT=8081 npm start
```

その場合は http://localhost:8081/ を開きます。
localhostと127.0.0.1、ポートの違いでブラウザの保存場所は変わります。

## 追加した機能
| 対象 | 機能 | 使い方 |
| --- | --- | --- |
| ToDo | タスク編集 | タスクの「編集」から名前・期限・難易度・メモを変更 |
| ToDo | 期限日とメモ | 通常タスク追加時に指定。過ぎた期限を強調表示 |
| ToDo | XP保護 | 完了済みタスクは獲得済みXP・難易度を維持 |
| ゲーム | 装備工房 | GOLDで武器・防具を購入し装備 |
| ゲーム | 6種類の装備 | 武器3種類、防具3種類。購入時は自動装備 |
| ゲーム | 成長連携 | ToDoのLEVELに装備の攻撃力・最大HPを加算 |
| 共通 | バックアップ | 設定画面でタスク・XP・毎日の設定・ゲーム・装備をJSON保存 |
| 共通 | 復元 | 内容を確認して復元。直前の記録も保護 |
| 共通 | PWA | 対応ブラウザからアプリとしてインストール |
| 共通 | オフライン | 設定画面で画像を含めて事前保存 |

通常タスクの追加は「タスクを追加」または一覧のすぐ追加から。
日々の繰り返し設定、検索、完了・未完了切り替え、5ステージごとのボス、クリア型遠征、必殺技演出は継続しています。
繰り返しタスクの「編集」はその日のタスクだけに反映します。今後の繰り返し設定は変更しません。
装備は戦闘中に購入・変更できません。HPなどへの反映は次の戦闘開始時です。

## アプリとして使う
1. ローカル版を起動し、設定画面を開きます。
2. 対応するPCのChrome/Edgeで、ブラウザのインストール操作を行います。
3. 「オフライン用に保存」を押し、「準備ができました」と表示されるまで待ちます。
4. 保存後は、通信やローカルサーバーが停止しても保存済みページ・ゲーム画像を読み込めます。

インストールの案内が出ないときは設定画面の「インストール方法」を確認してください。
iPhone/iPadではHTTPSで配信後、共有メニューから「ホーム画面に追加」を利用します。
PCのlocalhostはPWAの確認に使えますが、スマートフォンからPCの通常HTTPアドレスへ接続してもPWAのインストール条件は満たしません。
端末別の案内は [MDNのPWAインストール要件](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable) を参照しています。

ローカル開発時のキャッシュ混乱を防ぐため、オフライン機能は設定画面から有効にします。
有効化後もオンライン時は新しいファイルを取得し、通信失敗時に保存済みファイルを利用します。
公開する際に新しいファイルを追加したらoffline-files.jsの一覧も更新してください。版を更新する際はsw.jsのCACHE_NAMEも変更します。

## 記録を引き継ぐ
設定 → バックアップを保存 → 移行先の設定 → バックアップを復元。
復元は現在の記録を置き換えます。読み込む前に件数・XP・GOLDを表示します。
保存エラーが起きた場合は両方のデータを元に戻します。
「復元前の記録を保存」から、置き換える直前の記録も取り出せます。

このアプリはブラウザ保存です。ログイン・クラウド同期・権限付き共有は含みません。
公開サイトとローカル版の保存領域は別です。
公開版に書き出し機能がまだない場合、今回のバックアップボタンから公開版の保存領域を直接読むことはできません。
